Section 3.0 · After lunch

Code the driver, then go wireless

The H-bridge only listens to two pins: INA and INB. Your job in Arduino IDE is to set those pins HIGH or LOW for each direction. Then the ESP32 opens a local Wi-Fi shop so your phone can send the commands.

3.1 Motor driver code

Write applyDirection

You will fill in a function that takes a direction and writes the two pins. Use the same truth table from the H-bridge desk. Facilitators will tell you which ESP32 pins are INA and INB on your PCB.

Test yourself: “If I want reverse, which pin is HIGH?” If you can answer without peeking, you are ready to type.
Arduino IDE · applyDirection.ino
// dir: 0 = stop, 1 = forward, 2 = reverse
void applyDirection(int dir) {
  if (dir == 1) {
    digitalWrite(INA, HIGH);
    digitalWrite(INB, LOW);
  } else if (dir == 2) {
    digitalWrite(INA, LOW);
    digitalWrite(INB, HIGH);
  } else {
    digitalWrite(INA, LOW);
    digitalWrite(INB, LOW);
  }
}

Live pin line: digitalWrite(INA, LOW); digitalWrite(INB, LOW);
